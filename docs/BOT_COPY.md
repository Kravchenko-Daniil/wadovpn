# Wado VPN — публичные тексты бота

_Обновлено: 2026-04-19_

Тексты, которые видят пользователи **до** нажатия Start — настраиваются через BotFather (`/setabouttext`, `/setdescription`). Для текстов **внутри** бота смотри `bot/texts.py`.

## About (карточка бота, ≤120 символов)

```
Для близких, кому не нужен VPN, а нужно чтобы интернет работал
```

**Позиционирование через Jobs-to-be-Done:** продаём не инструмент (VPN), а исход (интернет как раньше). Reframing через отрицание категории — близкий не хочет «VPN» (технично и потенциально страшно), он хочет «чтобы YouTube снова открывался».

Рассмотренные альтернативы:
- «Для своих. Чтобы интернет работал.» — короче, «свои» теплее; отклонено, хотелось reframing через отрицание категории
- «Не VPN — чтобы интернет работал.» — короткий тизер без аудитории; отклонено, терялось «для близких»

## Description (splash-экран до Start, ≤512 символов, multi-line)

```
Сделано для своих.
Без настроек, без инструкций, без слова «VPN».

3 дня бесплатно, дальше 99₽/мес.

Нажми Start.
```

Работает в паре с About — не дублирует:
- **About** = хук на карточке («для кого и что даёт»)
- **Description** = первый экран («как это работает, сколько стоит, что делать»)

**Ключевые решения:**
- «Сделано для своих» перекликается с About («для близких»), но другими словами — не читается как повтор
- Тройной параллелизм «без … без … без» снимает главную объекцию близких одной строкой («я не разберусь / это сложно / это стрёмное слово»)
- Платформы (YouTube, Instagram, ChatGPT, …) **сознательно не перечислены** — выглядит как обычная реклама VPN и ломает позиционирование «не-VPN для своих». Решение принято автором.
- CTA «Нажми Start» — в Telegram под Description и так есть синяя кнопка, но для родственников старшего возраста нужно прямое «сделай это», иначе они могут зависнуть на экране

Рассмотренная альтернатива (боль через узнаваемые фразы):
```
Надоело «повторите позже» и «контент недоступен в вашем регионе»?

3 дня бесплатно, дальше от 99₽/мес — одна подписка на все устройства.

Нажми Start.
```
Отклонено — более жёсткий тон, не совпадает с тёплой подачей About.

## Принципы для будущих правок

1. **Не перечислять платформы.** Это выглядит как обычная реклама VPN и ломает позиционирование «не-VPN для своих».
2. **Держать тон тёплым**, без провокации и давления. Аудитория — близкие, не холодный рынок.
3. **Не раздувать длину.** About — на одном вдохе, Description — ≤3 секунды на чтение.
4. **Не писать «VPN» в позитивном ключе.** Только в отрицании («не VPN», «без слова “VPN”») — это часть позиционирования.
5. **Не обещать всемогущества** («всё работает», «любые сайты»). Reality-VPN не покрывает Netflix US / банки чужих стран / Upwork как резидент — см. `docs/TZ.md` §1.

## Как обновить

- **About:** в @BotFather → `/setabouttext` → выбрать `@wadovpn_bot` → вставить новый текст
- **Description:** `/setdescription` → `@wadovpn_bot` → вставить новый текст
- После правки — обновить этот файл, чтобы синхронизировать с актуальным состоянием бота
