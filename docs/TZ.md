# ТЗ: Wado VPN

_Версия 0.6 — 2026-04-19 (релиз, публичный запуск)_

## 1. Цель и суть

Telegram-бот, который раздаёт доступ к VPN-нодам (Xray) знакомым и платным клиентам. Собственных клиентских приложений НЕТ — пользователи ставят готовые (Hiddify, Streisand, v2rayNG, Amnezia, Shadowrocket и т.д.).

Масштаб старта: ~10 активных пользователей. Архитектура рассчитана на рост до 100-500 без переделок.

**Целевая аудитория:** жители РФ (в первую очередь Москва), которым нужен обход блокировок — YouTube, ChatGPT, Twitter/X, Instagram, Discord, Notion, GitHub Copilot и т.п.

**Что сервис НЕ обещает** (явно пишется в описании бота, чтобы управлять ожиданиями):
- ❌ Работу с Upwork, Fiverr, PayPal, Stripe при регистрации как резидент чужой страны
- ❌ Разблокировку региональных библиотек Netflix / HBO / Disney+
- ❌ Доступ к банковским приложениям стран, где юзер "не местный"
- ❌ "Анонимность" в полном смысле — datacenter-IP всё равно палится как `hosting/proxy` любым anti-fraud сервисом

Это следствие архитектуры self-hosted VPN в принципе, а не выбора провайдера. Для таких кейсов нужен residential proxy — это другой продукт и другой бизнес.

**Ключевой продуктовый принцип:** пользователь получает **subscription URL** (sub-link), а не статичный конфиг. Это даёт возможность чинить/ротировать конфиги на бэке без участия юзера — критично для борьбы с DPI и поломками клиентов после обновлений iOS.

**Главный механизм защиты от ТСПУ/DPI:** в одном sub-link отдаётся **4-5 разных протоколов/конфигов** (Reality на разных портах с разными SNI, gRPC+TLS, Shadowsocks-2022, AmneziaWG). Клиент (Hiddify/Streisand/v2rayNG) автоматически переключается на рабочий за несколько секунд. Юзер ручных действий не делает.

## 3. Пользовательские сценарии

### 3.1 Первый запуск
`/start` → приветствие → меню: `Попробовать бесплатно` / `Купить подписку`.

### 3.2 Пробный период
3 дня бесплатно. Один раз на Telegram ID. Выдаётся sub-link + инструкция.

### 3.3 Покупка подписки
Выбор тарифа → выбор способа оплаты → оплата → автоматическая активация → sub-link + инструкция.

### 3.4 Друг (бесплатно)
Три способа выдать бесплатный доступ:
- `/grant <tg_id> <days>` — на конкретный срок (роль `friend`, expires_at = +N дней)
- `/invite [max_uses] [note]` — генерит deeplink `t.me/wadovpn_bot?start=inv_xxx`, активация бессрочная
- `/whitelist add @user1 @user2 ...` — преднастройка по `@username`, авто-активация при первом `/start`

Бессрочные friend имеют `expires_at = NULL` и видят кнопку «💝 Поддержать проект» вместо «Купить подписку». Если они оплатят — их бессрочность сохраняется, бот шлёт благодарность и админ-нотификацию `💝 Донат от бессрочника`.

### 3.5 Продление
- После окончания подписки — sub-link перестаёт отдавать рабочие конфиги (в Marzban юзер блокируется).
- Напоминания (за 3/1/0 дней до конца) — **TODO Этап 1.5**, сейчас не реализованы.

### 3.6 Инструкции по установке
Кнопка **«Инструкция»** в меню → выбор платформы → пошаговая инструкция (скопировать sub-link → импорт в клиент). Даём 2-3 рекомендованных клиента на платформу с приоритетом (см. §9). QR-код — TODO.

### 3.7 Поддержка
Кнопка "Помощь" → FAQ → кнопка "Написать админу" (форвардит сообщение в личку админа).

### 5.3 Протоколы внутри sub-link

Юзеру отдаётся ОДНА ссылка, но внутри — несколько конфигов. Клиент сам выбирает рабочий. Это главная защита от DPI-поломок.

**Обязательные профили в sub-link:**

1. **VLESS + Reality** (порт 443) — основной, лучший anti-DPI
2. **VLESS + XHTTP или gRPC + TLS** через домен — fallback, когда Reality начинает палиться
3. **Shadowsocks-2022** — запасной, работает там, где Xray капризничает

**Опционально (если Amnezia остаётся параллельно):**
4. **AmneziaWG** — отдельный профиль для клиента Amnezia

## 8. Устройства на одну подписку

**MVP:** 1 подписка = **2-3 устройства одновременно** (настраивается через `ip_limit` в Marzban).

Обоснование:
- Xray технически поддерживает несколько подключений на один UUID
- У среднего юзера — телефон + ноут, "1 устройство" вызывает раздражение
- Marzban считает активные IP → можно жёстко ограничить

**Задел на v2:** ввести тарифы "Basic" (2 устройства), "Premium" (5 устройств) как рычаг монетизации.

## 9. Рекомендованные клиенты (в инструкции бота)

Политика: **даём 2-3 варианта на платформу с приоритетом**, не привязываемся к одному. Если после обновления iOS один клиент ломается — юзер переходит на следующий, sub-link остаётся тот же.

|---|---|---|---|
| **iOS** | Streisand | Hiddify | Karing / V2Box / Shadowrocket ($) |

| **Windows** | Hiddify-Next | Nekoray | v2rayN |
| **macOS** | Hiddify-Next | V2Box | Streisand |
| **Linux** | Hiddify-Next | sing-box (CLI) | — |

## 10. Anti-DPI и устойчивость

1. **Multi-protocol внутри sub-link** — всегда 3+ разных профиля
2. **Ротация Reality**: `shortId` меняется раз в 1-2 недели, SNI — раз в месяц (cron + Marzban API)
3. **Минимум 2 endpoint-ноды** в разных AS — одну выбило, вторая работает
4. **Probe из РФ** каждые 5 минут: HTTP + Reality handshake. При падении:
   - алерт админу
   - нода автоматически помечается "degraded" → sub-link временно не отдаёт её конфиги
5. **sub-link URL фронтится через Cloudflare** — чтобы саму ссылку не заблокировали
6. **Если все ноды легли** — бот рассылает всем активным юзерам сообщение "работаем над восстановлением, ETA N минут"

## 11. Данные и приватность

**Принципиально: не логируем трафик пользователей.**

Что храним:
- TG ID, username
- Дата регистрации, текущая подписка, история оплат
- Ссылки на sub-link (но не содержимое трафика)

Что отключаем:
- Access-логи Xray (`log.access: "none"` в конфиге)
- Расширенные логи Marzban
- История DNS-запросов

В приветствии бота и в описании — честно написано: "трафик не логируется, хранятся только данные оплаты".

## 13. Риски

| Риск | Вероятность | Митигация |
|---|---|---|
| Reality перестаёт проходить DPI | Высокая | Multi-protocol, ротация, probe |
| iOS-клиент ломается после обновления | Высокая | Несколько клиентов в инструкции |
| Endpoint-нода заблокирована | Средняя | Минимум 2 ноды, auto-exclude |
| Банк блокирует карту за СБП-переводы | Средняя | Stars как основной канал, СБП ручной |
| Marzban/Xray баги после обновления | Средняя | Не апать сразу, ждать 1-2 недели |
| Юр. претензии / жалобы | Низкая, но | Серая зона; не логировать; использовать анонимные реквизиты |
| Рост до 100+ юзеров → не тянет 1 нода | Средняя | Marzban рассчитан на это; добавить ноды горизонтально |
